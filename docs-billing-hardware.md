# Billing keyboard and scanner setup

Open Billing and select **Keyboard shortcuts** for the in-app guide. Search accepts a product name, SKU or barcode. Arrow keys select a result and Enter adds it to the bill. Ctrl+Enter reviews payment; Enter on **Confirm sale** submits it. Reprinting from Orders uses the saved sale.

For a keyboard-wedge scanner, configure **F9 prefix, barcode characters, Enter suffix**. Configure F9 as a function key, not the two characters F and 9. This prefix allows Billing to intercept the very first character while an editable field has focus. Without the prefix, scans in quantity, customer, or price fields behave like typing and can change their values. Outside editors, fast exact SKU/barcode input with an Enter suffix is supported. In product search, Enter selects the active result. Camera scanning remains available via F4.

F2 outside editable fields asks before clearing bill, customer, and payment details. F7 holds or resumes within the same browser tab and user account. F8 opens returns for users with refund permission. Delete removes the selected bill line outside an editor. F3 is reserved for the drawer; no hardware command is configured.

Hardware acceptance is pending. Check prefix and suffix, repeated scans, field contents and cursor position on the actual scanner. Check receipt fit and scan-readability using the printer driver and paper in use. Drawer commands require the printer/drawer model and connection details.
